 **EJERCICIO NAT**

Encontrarás un archivo con el ejemplo de la configuración completa de enrutadores que se desarrollará a la largo de este curso, puedes usarlo como material de estudio para este y otros capítulos siguientes.

[[09-ejemplo-configuracion.pkt]]

A continuación las instrucciones del ejercicio de NAT:

1.       Haz ping desde las máquinas de la red interna hacia el servidor de internet usando su ip

2.       Prueba la configuración de NAT que está hecha en la topología utilizando el comando que te permite ver las traducciones

3.       ¿Qué cambios deberías hacer a nivel de NAT si quisieras ampliar el pool de direcciones?

4.       Agrega una dirección adicional al pool de direcciones existente y verifica que sea usada.
